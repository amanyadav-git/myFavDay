# My Favorite Day — Birthday Website

A beautiful birthday celebration website for Anshika Amandeep Yadav's 20th birthday.

## Features

- Responsive design
- Beautiful typography with Fraunces and Sora fonts
- Photo gallery
- Smooth scrolling experience

## Getting Started

### Local Development

```bash
npm install
npm run dev
```

Visit `http://localhost:8080` in your browser.

### Deployment

This project is configured for Vercel deployment:

1. Push to a Git repository (GitHub, GitLab, or Bitbucket)
2. Connect your repository to Vercel
3. Vercel will automatically deploy on push

**Environment:** Node.js not required (static site)
